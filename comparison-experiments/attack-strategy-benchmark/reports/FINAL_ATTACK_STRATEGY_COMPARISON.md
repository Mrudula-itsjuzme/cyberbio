# Final Attack Strategy Comparison

## 1. Scope
This is an OPTIONAL comparison study extending the CyberBio project to establish a genuine, perfectly matched comparison between Bio-Cyber and Materials adversarial vulnerabilities.

## 2. Canonical vs Optional Study
The canonical results for both domains remain strictly separated and frozen. This optional study unifies query accounting, search limits, and attribution baseline comparisons.

## 3. Bio-Cyber Setup
- Clean Model: CNN_Distance
- Defended Model: CNN_Distance (mixed-adversarial)
- Task: Binary classification (distance sequence validation)
- N = 30 sources selected deterministically
- Budgets: 5, 20, 50 search queries

## 4. Materials Reconstruction
The Materials vocabulary was fully audited (`MATERIALS_VOCABULARY_FORENSICS.md`), verifying the native 37-token input shape successfully utilized the raw 36-token array plus an explicit padding index. `MATERIALS_MODEL_COMPATIBILITY` is `VERIFIED`.

## 5. Materials Setup
- Clean Model: TransformerRegressor
- Defended Model: Pending independent vocabulary/pipeline verification
- Task: Tg prediction (regression)
- N = 30 sources selected deterministically
- Budgets: 5, 20, 50 search queries
- Constraint: Candidates must successfully parse in RDKit.

## 6. Random
Random search serves as the baseline, evaluating candidates generated by simple mutations without model guidance. In Materials, naive token mutations result in severe RDKit validity collapse.

## 7. MCMC
Metropolis-style stochastic search guided by model predictions. Accepted candidates must improve or fall within an exponentially decayed drift bound.

## 8. Evolutionary
Population-based search guided by drift fitness. In tight constraints (N=5, 20), generating candidate populations rapidly consumes query budgets.

## 9. Attribution Controls
Targeting using sequence occlusion sensitivity. We compare targeting the highest attribution positions (Attribution-High) against random target positions (Attribution-Random).

## 10. Query Accounting
Total Queries = Search Queries + Attribution Queries.
Attribution generation costs $L$ model evaluations, where $L$ is sequence length. Bio-Cyber $L=150$.

## 11. Bio-Cyber Results
Attribution overhead vastly eclipses the search budget benefits. MCMC slightly outperforms Random, but statistical significance is low at N=30.

## 12. Materials Results
Attribution overhead is extremely expensive (L=~256). Token mutations yield very low valid candidate rates, meaning standard text-based perturbations spend the vast majority of search queries failing RDKit checks rather than evaluating useful properties.

## 13. Paired Statistics
Wilcoxon signed-rank and McNemar tests computed deterministically with 95% bootstrap CIs (n=1000 resamples, seed=42). Detailed metrics in `statistical_results.json`.

## 14. Validity
Bio-Cyber domain allows 100% syntactic validity. Materials domain strictly rejects non-physical molecular graphs, severely bottlenecking random or purely statistical search.

## 15. Attribution Overhead
In both domains, exact attribution calculations consume far more queries than the search phase (150-256 queries vs 5-50 queries).

## 16. Cross-Domain Comparison
The presence of strict chemical validity constraints limits search efficiency in Materials significantly more than in Bio-Cyber.

## 17. Defense Transfer Limitations
`MATERIALS_DEFENSE_TRANSFER = NOT_RUN`. The canonical 46-token defended model was not evaluated due to lack of separate verification for its defense-compatibility pipeline in this script.

## 18. Failure Cases
MCMC and Evolutionary frequently reject candidates or generate invalid strings, halting search progress under small absolute budgets.

## 19. Limitations
Sample size N=30 limits statistical power for detecting small differences.

## 20. Conclusions
High-attribution targeting provides marginal benefits that are completely nullified if total query accounting includes the attribution computation cost.

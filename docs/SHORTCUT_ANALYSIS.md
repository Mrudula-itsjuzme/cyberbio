# SHORTCUT ANALYSIS

## Demonstrated Evidence
- Sequence length is weakly correlated with true target (Pearson r=-0.487).
- Sequence length is somewhat associated with the model's prediction (Pearson r=-0.467).
- Absolute length change has an association with absolute prediction drift (Pearson r=0.279).

## Interpretation
Evidence is consistent with the model relying on sequence length as a partial proxy for properties, consistent with shortcut reliance, creating sensitivity to length-changing edits like insertions or deletions.
